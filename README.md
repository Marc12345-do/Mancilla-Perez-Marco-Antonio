# CI Pipeline para Laravel / PHP con GitHub Actions

## Objetivo
Automatizar la instalación de dependencias, validaciones de sintaxis y ejecución de pruebas automatizadas sobre una aplicación Laravel utilizando GitHub Actions cada vez que se envíen cambios a la rama principal (`main`).

## Tecnologías Utilizadas
* **Lenguaje:** PHP 8.2
* **Framework:** Laravel
* **Gestor de Dependencias:** Composer
* **Testing:** PHPUnit / Artisan Test
* **Control de Versiones & CI/CD:** Git, GitHub, GitHub Actions
